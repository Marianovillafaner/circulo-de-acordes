# Círculo de acordes

Web interactiva para aprender armonía con armónica diatónica.

- Círculo de quintas con acordes mayores y menores, y las notas numeradas del 1 al 12
- Tablatura de la armónica en cualquier tonalidad, con lector de tablaturas
- Escala pentatónica
- Pulso, compás y acento, con metrónomo y ejercicios de respiración
- Blues de 12 compases con turnaround y ending, usando *Down Home Blues* (Harp Attack!, 1990) de ejemplo

Es un solo archivo (`index.html`), sin dependencias ni compilación. Se publica con Cloudflare Pages.
